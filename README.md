# Sea to Sky Rental Prototype

This repository contains the prototype setup for the Sea to Sky Rental redesign.

## Stack

- `Next.js`
- `TypeScript`
- `Tailwind CSS`
- `Motion`

## Run

```bash
pnpm dev
```

## Install

```bash
pnpm install
```
